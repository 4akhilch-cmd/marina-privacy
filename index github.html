Marina Uploader – Privacy Policy

Last updated: 14 November 2026

Marina Uploader is a private desktop tool used by its owner to upload videos he has produced to YouTube channels that he owns. It is not offered to the public.

What the app accesses

With the channel owner's permission (given on Google's consent screen), the app uses the YouTube Data API to:

  • upload videos, titles, descriptions, tags and thumbnails to the owner's channels;
  • read the basic name and ID of the connected channel, to confirm the right channel is selected.

How data is stored

Login tokens are stored only on the owner's own computer. The app has no server, does not collect data from other YouTube users, and does not share, sell or transfer any data to third parties.

YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also removes all stored data.
